# AGENTS.md

Перед любыми изменениями обязательно прочитать:

- docs/MARTYSKIN_WORLD.md
- docs/CODEX_ANDROID_UPDATE_MASTER_TASK.md
- docs/CODEX_MARTYSKIN_VIDEO_REVIEW_PROMPT.md
- docs/CODEX_MARTYSKIN_POST_CLEANUP.md

Правила:
- Не удалять рабочие фичи из Android-версии.
- Не заменять фон градиентом/сеткой/космосом, если уровень не космический.
- Не делать бананы лимонами.
- Не делать примата без ног.
- Не убирать русские надписи.
- Android и Web должны использовать единые configs/level data.
- После правок выполнить минимум 4 цикла проверки.
- После финального успешного билда выполнить post-cleanup.
