# Android emulator QA

## Target

- AVD: `MTR_Galaxy_S25_Ultra_Android_16`
- Android: 16 / API 36
- Image: Google APIs x86_64
- Display: 1440×3120, 500 dpi, 120 Hz-capable
- Runtime landscape size: 3120×1440
- RAM: 12 GB
- CPU: 8 vCPU
- GPU: AMD Radeon 890M through Android Emulator OpenGL ES Translator
- GLES: 3.1

This profile approximates the Galaxy S25 Ultra screen class and Android version while retaining the speed and tooling quality of x86_64 virtualization. It does not emulate One UI 8.5, Snapdragon, Adreno, S Pen or Samsung services.
