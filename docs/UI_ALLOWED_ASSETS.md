# MTR UI allowed assets contract

Дата фиксации: 2026-06-19.

## Интерактивные кнопки

- Графическая кнопка должна быть blank/base PNG без baked-текста.
- Весь читаемый текст кнопки рисуется рантаймом через `GameRoot.text(...)`.
- Исключение: канонический skin-pack главного меню
  `assets/resources/objectives/themed/last_iteration/ui/main_menu/button/*.png`.
  Эти шесть кнопок являются цельными PNG-элементами с уже встроенной надписью;
  поверх них запрещено рисовать runtime-текст, shared-кнопку или
  `buttonLabelPlate`.
- Runtime-плашка `UI_SKIN.assets.buttonLabelPlate` используется только как fallback
  или на gameplay/HUD-кнопках, где нужен дополнительный контраст. На обычных
  меню-кнопках поверх валидной blank/base PNG её рисовать нельзя: это создаёт
  лишний "луковый" слой.
- Запрещено добавлять новые PNG-кнопки с уже впечанными русскими подписями,
  если эта подпись дублирует runtime-текст и не оформлена как отдельный
  канонический атомарный skin-pack элемент.

## Меню выбора уровней

- Иконки тематик уровней — отдельные RGBA PNG 128x128.
- Канонический набор: `assets/resources/objectives/themed/last_iteration/ui/level_select/icon/mtr_level_select_theme_icon_01..15.png`.
- Все 15 уровней должны иметь собственную PNG-иконку; повторение заглушки уровня 8 для уровней 9+ запрещено.
- `GameRoot.drawLevelThemeIcon(...)` не должен возвращаться к ручной векторной отрисовке тематик: визуальный источник — PNG-ассеты плюс безопасный fallback, пока ресурс догружается.

## Фон главного меню

- Главное меню использует только один приглушенный дальний PNG-фон
  `assets/resources/ui/main_menu_background/main_menu_bg_far.png` плюс единый
  runtime haze-слой.
- `main_menu_bg_far.png` должен оставаться цельной стилизованной scenic-картинкой,
  а не набором заплаток/слоёв. В центральной safe-zone меню запрещены читаемые
  ghost-надписи, старые UI-пропсы и элементы, которые выглядят как подложенный
  текст под новыми PNG-кнопками.
- Читаемый текст, цифры, UI-таблички, логотипы и старые ghost-надписи запрещены
  по всему фону. Лор передаётся через картинку: джунгли, стройку, бананы,
  инструменты, рельсы, бамбуковые леса и силуэты, но не через baked-текст.
- Старые `main_menu_bg_mid`, `main_menu_bg_near_*`,
  `main_menu_bg_top_hanging`, `main_menu_bg_bottom_foreground` и
  `main_menu_grade_overlay`, а также `main_menu_decor_props_sheet`, считаются
  legacy-исходниками/доказательствами и не должны попадать в активную
  runtime-отрисовку или runtime `assets/resources` главного меню. Архив
  r9: `docs/qa/evidence/main_menu_legacy_layers_20260619_r9/`.
- Предыдущая версия far-фона с локальными de-text заплатками запрещена к
  использованию как финальный фон: она ломает требование цельной картинки.
- Исходный far-фон до single-layer адаптации сохранён только как QA evidence:
  `docs/qa/evidence/main_menu_bg_far_before_deonion_20260619_r9.png`.
- Любое возвращение дополнительных фоновых слоёв главного меню требует нового
  UI QA-checkpoint с визуальным доказательством, что не появился "луковый"
  эффект и не читаются подложенные старые надписи.

## Hygiene gate

- В конце каждого существенного патча выполняется обязательная зачистка хвостов: dead code, временные файлы, старые комментарии, superseded generated artifacts, неиспользуемые ассеты и тяжёлый мусор.
- Чистка допустима только после релевантной проверки, чтобы не удалить аудит-логи, исходные доказательства, финальные checkpoint-файлы и ассеты, нужные для воспроизводимости.
- Legacy-ассеты удаляются только когда подтверждено, что они не находятся в generated catalog, resource manifest или активном runtime preload path.

## Известный legacy-хвост

- Старые шесть `mtr_last_level_select_ui_level_select_icon_01..06` всё ещё упоминаются в `assets/scripts/generated/ThemeAssetCatalog.generated.ts`.
- Их нельзя удалять механически до регенерации/очистки generated catalog и повторной сборки; это отдельный safe-cleanup шаг после прохождения UI QA.
