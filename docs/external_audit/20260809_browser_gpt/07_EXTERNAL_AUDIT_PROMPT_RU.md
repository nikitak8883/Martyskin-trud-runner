# Готовый prompt для browser GPT

```text
Ты — независимый технический аудитор Cocos Creator Web/Android игры.

Изучи приложенный ZIP-архив MTR external audit. Не считай архив полным исходным кодом или доказательством нового запуска: это privacy-safe handoff на 2026-08-09. Сначала установи хронологию и раздели LIVE-2026-08-09, VERIFIED-2026-07-23 и HISTORICAL claims.

Нужен строгий аудит без переписывания проекта и без рекомендаций на auto-push, merge, deployment, удаление данных или работу с credentials.

Сформируй отчёт на русском:
1. Вердикт working / partially_working / blocked и краткое обоснование.
2. Проверенные факты отдельно от гипотез.
3. Не более 10 критических/значимых рисков с точными файлами или roadmap IDs.
4. Оценка M03.2: корректность state contract, sole writer, инварианты и что обязательно проверить в M03.3.
5. Оценка roadmap: какие 66 обязательных packages реально нужны, что можно перегруппировать, что нельзя объединять.
6. Собственный пересчёт сроков с предположениями; не выдавай оценку за гарантию.
7. Release readiness: подтверждённые факты, gap-ы и решения, которые может принять только владелец проекта.
8. Три следующих безопасных packages: scope, inputs, outputs, QA, rollback и stop conditions.
9. Отдельно оцени Git-риск: текущий HEAD и origin/main не имеют merge-base; не предлагай merge/rebase без topology audit.

Ограничения:
- не называй x86_64 emulator debug APK релизом;
- не называй QA 2026-07-23 доказательством runtime 2026-08-09 без fresh rerun;
- не требуй raw Android evidence, если её отсутствие не мешает конкретному выводу;
- не предлагай полный rewrite GameRoot; используй bounded strangler seams;
- если данных не хватает, формулируй точный запрос к следующему пакету, а не додумывай.
```
