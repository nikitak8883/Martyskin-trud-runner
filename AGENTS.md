# AGENTS.md

Перед любыми изменениями обязательно прочитать:

- docs/MARTYSKIN_WORLD.md
- docs/CODEX_ANDROID_UPDATE_MASTER_TASK.md
- docs/CODEX_MARTYSKIN_VIDEO_REVIEW_PROMPT.md
- docs/CODEX_MARTYSKIN_POST_CLEANUP.md

Правила:
- Не удалять рабочие фичи из Android-версии.
- Не заменять фон градиентом/сеткой/космосом, если уровень не космический.
- Не делать бананы лимонами.
- Не делать примата без ног.
- Не убирать русские надписи.
- Android и Web должны использовать единые configs/level data.
- Любой Android QA-эмулятор запускать только с `-no-audio`; перед каждым runtime-прогоном принудительно выставлять media stream 3 в `0` и fail-closed проверять результат. Без подтверждённой тишины тест не запускать.
- Любой Web QA запускать с `--mute-audio`; не отключать аудиокод продукта и не менять пользовательские настройки ради тишины на хосте. Аудиопроверки выполнять без вывода звука.
- Для сравнительных измерений Android использовать явно подтверждённый `Test-MtrAndroidToolchain.ps1 -EnsureEmulator -ColdBoot`; это выключает загрузку/сохранение snapshots, но не очищает userdata или дисковые caches. Уже открытый эмулятор не считать холодным и не закрывать без проверки принадлежности.
- После правок выполнить минимум 4 цикла проверки.
- После финального успешного билда выполнить post-cleanup.
