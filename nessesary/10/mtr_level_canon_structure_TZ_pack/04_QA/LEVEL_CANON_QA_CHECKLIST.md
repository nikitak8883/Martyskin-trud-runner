# QA — Level Canon Checklist

Для каждого уровня проверить:

- [ ] ID совпадает с каноном
- [ ] название совпадает с каноном
- [ ] тема совпадает с каноном
- [ ] фон соответствует теме
- [ ] платформы соответствуют теме
- [ ] hazards соответствуют теме
- [ ] collectibles не забивают экран
- [ ] progression props есть или запланированы
- [ ] UI-card соответствует уровню
- [ ] нет случайного ассетного микса
- [ ] юмор соответствует уровню
- [ ] нет читаемого английского текста без причины
- [ ] нет белых пятен у PNG
- [ ] фон не спорит с gameplay layer

Финальный статус по уровню:

```text
LEVEL CANON ACCEPTED / LEVEL CANON NOT ACCEPTED
```
