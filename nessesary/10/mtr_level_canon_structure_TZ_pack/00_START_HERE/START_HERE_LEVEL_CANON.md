# START HERE — MTR Level Canon Structure TZ

## Что это

Это канонический документ по 15 уровням игры **«Мартышкин труд Runner»**.

Перед любыми правками уровней, фонов, платформ, препятствий, UI-карточек, achievements и ассетов Codex обязан прочитать:

```text
01_MASTER_TZ/MTR_LEVEL_CANON_STRUCTURE_TZ.md
02_CONFIG/mtr_level_canon_manifest.json
```

## Главный запрет

Не менять названия, темы и порядок уровней без отдельного разрешения.

## Главная задача

Использовать документ как структурную базу:

```text
уровень -> тема -> фон -> платформы -> hazards -> collectibles -> UI -> QA
```

## Порядок работы Codex

1. Прочитать Master TZ.
2. Прочитать JSON manifest.
3. Создать readback:
   ```text
   qa/level_canon_initial_readback.md
   ```
4. Для каждой задачи указывать:
   - какой уровень затронут;
   - какая часть канона затронута;
   - какие ассеты/конфиги изменены;
   - не нарушена ли тема уровня.
