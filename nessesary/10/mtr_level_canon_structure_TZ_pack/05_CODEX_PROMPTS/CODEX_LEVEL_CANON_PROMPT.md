# Codex Prompt — Level Canon

Используй этот пакет как каноническую базу 15 уровней.

Не меняй:
- порядок уровней;
- названия уровней;
- основные темы;
- лор-роль уровня.

Перед правками создай readback.

Любая новая платформа, фон, hazard, UI-card или prop должны быть привязаны к конкретному уровню и теме.

Если ассет не соответствует теме уровня — не интегрировать.
