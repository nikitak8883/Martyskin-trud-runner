# Аудит загруженного пака `9.zip` — недостающие текстуры

## 1. Что внутри пака

Пак содержит **37 PNG**:

- **30 больших asset/UI sheets** из генераций `ChatGPT Image...`.
- **7 UI-наборов уровней 09–15** в папке `mtr_ui_missing_levels_09_15_png_sets/`.

## 2. Критичная техническая проблема

Первые **30 PNG** в архиве имеют режим **RGB**, то есть **без настоящего альфа-канала**.

Визуально на них есть шахматная подложка, но технически это не прозрачность, а запечённые пиксели фона.

### Что это значит

Для Cocos эти PNG нельзя считать готовыми transparent spritesheets.

Нужно одно из двух:

```text
Вариант A: перегенерировать true RGBA PNG с прозрачным фоном.
Вариант B: вручную/скриптом вырезать объекты, удалить шахматку, сохранить каждый объект или sheet как RGBA.
```

## 3. Что уже покрыто по смыслу

Пак хорошо покрывает:

- строительство / базовые платформы;
- логистику / склад / банановые ящики;
- офис / бюрократию;

- инспекцию / павлина / контроль;

- архив / шкафы / документы;
- generic safety/control props;
- меню, достижения, рекорды, выбор уровня, выбор примата, звук, dev mode, pause, death screen;
- UI-карточки уровней 09–15.

## 5. P1 — недостающие gameplay-текстуры по уровням

### Уровень 1 — Стройплощадка примата

Есть хорошее покрытие. Недостаёт:

- true-alpha cutout variants;
- 2–3 чистые основные платформы без лишних предметов сверху;
- отдельные hazards: падающий кирпич, смета, бетон, кривое окно;
- отдельные signage sprites без запечённой шахматки.

### Уровень 2 — Банановая логистика

Есть базовое покрытие. Недостаёт:

- true-alpha паллеты/ящики/тележки;
- отдельный погрузчик;
- конвейерные элементы;

- signage: «ПРИЁМ БАНАНОВ», «ОТГРУЗКА», «НЕ КИДАТЬ — ЭТО ГРУЗ».

## 6. P1 — недостающие фоновые пакеты

В `9.zip` нет полноценной инженерной фоновой структуры:


## 8. Вывод

Пак хороший как stylistic reference и UI/object source, но ещё не является готовым production atlas.

Главные пробелы:

```text
1. Нет true alpha у первых 30 PNG.
2. Нет atomized sprites.
3. Нет полных background packs 1–15.
4. Нет gameplay packs для уровней 9–15.
5. Нет полной player animation/equipment matrix внутри этого zip.
```
